# 文墨天机 - 专业命理测算小程序

## 项目概述

文墨天机是一款基于 uni-app 开发的微信小程序，提供专业的八字排盘和六爻占卜功能。采用古典水墨风格设计，体现传统周易文化的专业性和神秘感。

## 核心功能

### 1. 八字排盘
- **基础信息输入**：支持阳历/阴历转换，真太阳时校正
- **自动排盘**：
  - 四柱八字（年柱、月柱、日柱、时柱）
  - 十神分析（正官、偏官、正印、偏印等）
  - 五行旺衰分析
  - 大运流年推算
- **命盘解读**：自动生成命理分析报告

### 2. 六爻占卜
- **多种起卦方式**：
  - 数字起卦：输入三个数字
  - 铜钱摇卦：模拟三枚铜钱摇卦过程
  - 时间起卦：以当前时间起卦
  - 随机起卦：系统自动随机
- **卦象解析**：自动排卦、变卦、动爻分析
- **断卦参考**：基于经典卦辞和爻辞提供解读

### 3. 用户系统
- **微信一键登录**：利用 uni.getUserProfile 获取用户信息
- **用户档案管理**：保存出生年月日时、性别等基础信息
- **测算历史记录**：查看过往八字排盘和占卜记录

### 4. 反馈评价系统
- **准确度评分**：1-5 星评价机制
- **详细反馈**：用户可填写具体反馈内容
- **数据收集**：记录用户反馈用于算法优化
- **算法迭代**：定期分析反馈数据，优化解读逻辑

## 核心算法

### 八字排盘算法
1. **阳历转阴历**：使用农历转换算法
2. **四柱计算**：
   - 年柱：根据立春节点确定年干支
   - 月柱：根据节气确定月干支
   - 日柱：基于已知基准日推算
   - 时柱：根据日干和时辰确定时干支
3. **十神推算**：根据日干与其他干支的五行生克关系
4. **大运排列**：根据性别和年柱阴阳顺逆排列
5. **五行统计**：统计八字中金木水火土的数量和旺衰

### 六爻占卜算法
1. **起卦方法**：
   - 数字起卦：将数字转化为上下卦
   - 铜钱起卦：模拟铜钱正反面，计算爻的阴阳
2. **卦象确定**：根据上下卦组合确定 64 卦之一
3. **动爻计算**：确定变爻位置
4. **变卦推导**：根据动爻变化推导变卦
5. **卦辞匹配**：从数据库匹配对应的卦辞和爻辞

## 云开发配置

### 1. 创建云开发环境
1. 登录微信公众平台
2. 进入"云开发"控制台
3. 创建新的云开发环境
4. 记录环境 ID

### 2. 配置云函数
1. 在 `manifest.json` 中配置云开发环境 ID
2. 在微信开发者工具中右键云函数目录，选择"创建并部署：云端安装依赖"

### 3. 数据库集合
需要创建以下集合：
- `users`：用户信息
- `calculation_records`：八字测算记录
- `divination_records`：六爻占卜记录
- `feedback`：用户反馈
- `config`：系统配置
- `gua_data`：卦象数据
